> 작성 기준일: 2026-07-30 · 복식학급 실시간 원격수업 + AI 학습보조 플랫폼
> 상태 태그: **✅ 완료 · 🔄 진행 중 · ⬜ 예정 · ⏸ 후순위** — 뒤의 `(키)`는 JIRA 이슈 번호

---

## 배경 요약

**복식학급** — 농어촌·도서벽지 초등학교에서 교실·교사 부족으로 **서로 다른 2개 이상 학년을 한 교실에서 교사 1명이 동시에 가르치는 학급**. 저출생으로 전국적으로 계속 증가 중.

| 문제 | → | 말랑말랑의 기대효과 |
|---|---|---|
| 한 학년 실질 수업시간이 절반(40분→20분)으로 줄어 학습권 침해 | → | 공백 시간을 AI 학습보조로 채워 **학습권 회복** |
| 교사가 한 학년 지도 중 다른 학년은 공백·방치 → 학습 결손 누적 | → | 수준별 문제·난이도 조정으로 **학습 격차 완화** |
| 1명 학급·극소규모 증가, 또래 상호작용 부족 | → | 실시간 팀 수업으로 **또래 협력 경험 보완** |
| 협력강사 등 인적 지원 불안정·축소 | → | 강사 없는 시간대 보완 → **인적 의존도 완화** |
| 학습 자료·디지털 도구 파편화 | → | 자료·문제·이력 통합으로 **교사 준비 부담 경감** |

## [선생님]

### 1. 회원가입 ✅ `(15)`
- 받는 데이터: 이메일, 재직학교, 이름, 비밀번호

### 2. 로그인 ✅ `(19)`
- 이메일 + 비밀번호로 로그인

### 3. 학급(Classroom) 생성 및 관리 · *Epic 학급 생성 및 관리 `(82)`*
1. 담당자(선생님)가 학급을 생성한다 (As Owner) — 🔄 `(23)`
   - 담당자를 넘겨줄 수 있는 기능 — *추후 (JIRA 미등록)*
2. 다른 선생님을 관리자(As Maintainer)로 지정해 초대 — ⬜ `(24)` *(초대 발급·수락 인프라 ✅ `(112)`)*
3. 한 선생님이 복수 학급 담당 가능 — ✅ `(25)`
4. 열려있는 학급 확인·입장 — ✅ `(106 조회 API)`
- ➕ 학급 생성 시 담당 학년 선택 + 목록에 학년 표시 — ⬜ `(126)`
- ➕ CSV 학생 일괄 등록 ✅ `(110)` · 학급 수정·삭제+구성원 제외 ✅ `(111)` · 구성원 목록+비밀번호 초기화 ✅ `(115)`

### 4. 학급에 가입 (다른 선생님 학급에 Maintainer로) — ⬜ `(24, Epic 83)`
> 💡 3-b·d / 4-a = "선생님이 다른 선생님을 초대하고 싶다" 로 묶임 → **선생님 협업/초대 관리 Epic `(83)`**, 발급·수락 `(112 ✅)`

### 5. 수업 진행

#### 5.1 미디어 공유 (WebRTC) · *Epic 실시간 수업 세션 `(89)`*
1. 실시간 화면 공유 — ✅ `(26)`
2. 실시간 카메라 공유 — ✅ `(27)`
3. 수업 중 목소리 겹침 제어 — ⏸ 후순위 (학생 발화 → 자막/TTS `(43)`)
4. 학생 미디어는 팀 진입 시에만 접근 — *(참가자 명단 API ✅ `(107)`)*
5. 학생 실시간 카메라 확인 ✅ `(45)` · 학생 공유 화면 보기 ⬜ `(44)`
6. 전체/개인 마이크 끄기 🔄 `(46)` · 선생님 마이크 켜기 ✅ `(104)`
7. 학생 캠 끄기 — ⬜ `(47)`
8. 화이트보드 — **부분 완료**: 수정 ✅ `(123)` · 판서 권한 ✅ `(109)` / 신규 사용 ⏸ `(40)`
- ➕ 미디어 옵션 전체 일괄 적용 — 🔄 `(128)`

#### 5.2 학생 관리 · *Epic 학생·팀 데이터 관리 `(84)`*
1. 학생 초대·등록 (선생님이 아이디/비번 부여 — 현재안: CSV)
   - CSV/엑셀 일괄 등록 ✅ `(110)` · 아이디·비밀번호 부여·초기화 ✅ `(115)` · 부여된 아이디로 학생 접근 = 학생 로그인 ✅ `(70)`
2. 학급에서 제외(강퇴) — ⬜ `(49)`
3. 팀(그룹) 추가 ⬜ `(50)` / 제외 ⬜ `(48)` · 학년별 팀 자동 배정 ✅ `(101)`
4. 학생 목록 조회 — ⬜ `(52)`
5. 학생 개인 학습 이력 관리 (국어 한정, 추후 확장) · *Epic 학습 이력 `(85)`*

   2. 제출 과제 현황(학습 이력) 조회 — ✅ `(54)`
   3. 개별 학생 이해도 조회 — ✅ `(55)` *(= AI 분석/통계 기반 지표)*
   4. ~~학급 전체 이해도 통계~~ → **재검토**: 학급 히트맵이 v1.0으로 구현됨

#### 5.3 과제 생성 및 관리 (AI 학습 보조) · *Epic AI 과제 생성·관리 `(86)`*
