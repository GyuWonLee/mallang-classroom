# 말랑교실 — 기획 미결정 항목 & 로드맵

기존 기능 스펙 문서와 팀 논의를 기준으로, 아직 결정되지 않은 기획 항목과 남은 화면 작업 우선순위를 정리한 문서입니다.

---

## 1. 기획 미결정 항목

### 담당자(Owner) 이양
- **필요 여부**: 선생님 퇴사/휴직 시 학급이 붕 뜨는 상황을 막으려면 필요할 가능성 높음
- **정할 것**: 이양은 기존 Owner만 가능한지, Maintainer 중에서만 지정 가능한지, 이양 후 기존 Owner 권한은 어떻게 되는지
- **우선순위**: 낮음 — 초기 스프린트엔 없어도 서비스 운영 가능, 추후 기능으로 미뤄도 됨

### 목소리 겹침 제어
- **정할 것**: TTS 변환은 누가 트리거하는지(자동 감지 vs 학생이 직접 버튼), 변환된 텍스트는 선생님 화면 어디에 노출되는지(채팅창? 별도 알림?)
- **우선순위**: 중간 — WebRTC 화면 UX에 영향을 주므로 실시간 수업 화면 만들기 전에 정해야 함

### 초대 링크 수락/거절
- **현재 확정**: 이번 스프린트는 자동 가입
- **추후 논의**: 수동 승인이 필요해지면 "대기 중인 가입 요청" 리스트 화면이 추가로 필요함 — 지금은 스킵해도 되지만 화면이 하나 늘어난다는 것만 인지
- **우선순위**: 낮음

### "과제 관리"의 범위
- **정할 것**: 수정, 삭제, 재사용(템플릿화), 특정 학생/팀 대상 재배포 중 어디까지 포함할지
- **우선순위**: 높음 — 과제 생성 마법사 화면을 만들 때 바로 필요한 정보

### 쉬는시간 Lock
- **정할 것**: 락이 걸리면 학생이 뭘 못 하는지 (화면 공유만 막는지, 채팅도 막는지, 접속 자체를 막는지)
- **우선순위**: 중간 — 팀 관리 화면의 토글 하나짜리 기능이라 화면 자체는 간단하지만, 동작 정의는 필요

### 국어 콘텐츠 리서치
- **담당**: 재성님 액션 아이템으로 남아있음 (속담/이야기 기반 문제 설계 전 교과서 리서치)
- **우선순위**: 콘텐츠 제작 착수 전 필요, 디자인 작업과는 별도 트랙으로 병행 가능

### 학급 전체 이해도 통계
- **현재**: 스펙 문서에서 취소선 처리되어 이번 범위에서 제외된 것으로 보임
- **정할 것**: 팀 미팅에서 한 번 더 스코프 확인 필요

---

## 2. 남은 화면 — 우선순위 순

| 순서 | 화면 | 전제 조건 |
|---|---|---|
| 1 | 과제 생성 마법사 | "과제 관리" 범위 결정 필요 |
| 2 | 팀(그룹) 관리 화면 | 쉬는시간 Lock 동작 정의 필요 |
| 3 | 채팅 인박스 상세 | 없음 — 바로 착수 가능 |
| 4 | 학생 개인 이해도 대시보드 | 이해도 지표 산출 로직(AI/통계) 확정 필요 — 디자인보다 백엔드 결정이 선행 |
| 5 | 식물 키우기 위젯 | 없음 — 바로 착수 가능, PoC 진행 중인 항목 |

---

## 3. 전체 로드맵

1. **지금 바로 착수 가능**: 채팅 인박스, 식물 키우기 위젯 — 결정 대기 없이 바로 디자인 가능
2. **팀 미팅에서 확정 후 착수**: 과제 관리 범위, 쉬는시간 Lock 동작 → 과제 마법사, 팀 관리 화면
3. **백엔드 로직 확정 후 착수**: 이해도 산출 방식 → 이해도 대시보드
4. **후순위 (스코프 아웃 가능)**: 담당자 이양, 목소리 겹침 TTS, 화이트보드, 음성 메시지
